# Decisiones de arquitectura (ADR)

Una decisión por archivo, numerada: `NNNN-titulo-en-kebab-case.md`. Nunca se edita una decisión aceptada; si cambia, se escribe una nueva que la reemplaza y se marca la vieja como "Reemplazada por NNNN".

Plantilla:

```markdown
# NNNN. Título

Fecha: AAAA-MM-DD · Estado: Aceptada | Reemplazada por NNNN

## Contexto

Qué problema o pregunta había.

## Decisión

Qué se decidió y por qué.

## Consecuencias

Qué gana y qué pierde el equipo con esto.
```
